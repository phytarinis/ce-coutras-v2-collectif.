# Ressources de l’accueil

## Originaux conservés sans modification

Les cinq fichiers fournis sur GitHub sont regroupés dans `originals/` :

- `Le bazar d’E2C Coutras.png` : maquette de référence ; son logo Labo Épicé
  est cadré en CSS dans l’accueil, sans afficher la maquette entière ;
- `images (8).jpeg` : photographie du bâtiment E2C (638 × 480) ;
- `Portrait studio d’un homme en veste verte-2.png` : portrait retenu pour KØZMO ;
- `Portrait athleisure vert et crème-1.png` et
  `Portrait urbain en survêtement vert foncé-4.png` : autres portraits conservés.

## Fichier dérivé

`derived/kozmo.png` est une version à fond transparent du portrait studio,
préparée avec l’outil de retouche d’image. L’original reste conservé. Aucun nouveau
personnage, nouvelle pose ou décor n’a été demandé. La pose fournie diffère de
celle de la maquette. Le portrait détouré est un dérivé à valider visuellement.

Aucune image externe n’est utilisée. Aucun téléchargement réseau n’est nécessaire
pendant le jeu. Les crédits et droits restent ceux des ressources fournies.
Pour améliorer la netteté, fournir si possible la photo du bâtiment en haute
résolution et le logo Labo Épicé séparément.
